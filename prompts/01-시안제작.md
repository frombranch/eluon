# 프롬프트 01 — Eluon으로 시안 만들기

가장 많이 쓰는 프롬프트입니다. `<>` 부분만 바꿔서 씁니다.

---

## A. 기본형 — 코드로 재현 (권장)

이미지를 붙이는 게 아니라 **토큰 CSS + spec으로 실제 컴포넌트를 만듭니다.**
결과물이 살아있는 화면이라 반응형·상태·접근성까지 그대로 이어집니다.

```
Eluon 디자인 시스템으로 <화면 이름> 시안을 만들어줘.

시스템: https://github.com/frombranch/eluon
테마: eluo

순서
1. CLAUDE.md 와 manifest.json 을 먼저 읽어.
2. 이 화면에 필요한 자산 ID 목록을 먼저 나한테 보고해. 내 승인 전에 그리지 마.
   - manifest에 없는 게 필요하면 "없음"이라고 말하고 대체안 2개를 제시해.
3. 승인 후 단일 HTML로 조립해.
   - <link>로 docs/tokens/eluon-eluo.css 를 불러오고, 색은 전부 var(--color-*) 로.
   - 수치는 manifest의 specByTheme.<테마> 값 그대로. 바꾸지 마.
     (spec 은 토큰 이름이라 숫자가 아니야. 실제 px 는 specByTheme 에 있어.)
   - manifest에 없는 색·라운드·폰트를 새로 도입하지 마.
4. 자산을 놓기 전에 manifest 의 foundationByTheme.<테마> 를 먼저 읽어.
   - layout: 콘텐츠 최대폭·거터·그리드 열·열 간격·섹션 상하 여백·제목↔본문 간격·
     본문 한 줄 길이(ch). 캔버스가 넓어도 본문은 최대폭 안에 두고 가운데 정렬해.
   - typography: 스타일마다 "어디에 쓰는지"(role)가 적혀 있어. 그 자리에 그걸 써.
     크기를 숫자로 쓰지 말고 var(--type-<이름>-size), 또는 한 줄 축약형
     font:var(--type-heading1) 을 써. display1 은 한 화면에 하나뿐이야.
   - 간격은 임의값 말고 var(--space-*) 에서 골라. 섹션마다 여백을 다르게 주지 마.
5. 마지막에 사용한 자산 ID 목록과, specByTheme 에서 벗어난 부분이 있으면 그 이유를 적어줘.

화면 조건
- 대상: <B2B 채용 담당자 / 일반 소비자 / ...>
- 목적: <무료 체험 신청 전환>
- 섹션: <히어로 / 3단 밸류 / 사례 / 최종 CTA>
- 폭: 1440 데스크톱 기준
```

## B. 몽타주 시트 첨부형 — 탐색 단계

`index/sheet-eluo.png` 한 장을 첨부하고:

```
첨부한 시트가 우리 라이브러리 전체(30개)야.
<화면 이름>을 짜려는데 이 안에서만 골라서 구성안을 만들어줘.

- 섹션별로 어떤 ID를 쓸지 표로 (섹션 / 자산 ID / 이유)
- 시트에 없어서 새로 만들어야 하는 건 따로 목록으로
- 아직 코드는 쓰지 마. 구성안만.
```

## C. 고객사 테마로

```
Eluon 구조는 그대로 두고 <고객사> 브랜드로 테마만 만들어줘.
컴포넌트 레시피는 절대 건드리지 않는다는 전제야.

- 첨부: 고객사 BI 가이드 / 기존 사이트 캡처
- 산출: tokens/theme-<고객사>.json (theme-eluo.json 형식 그대로)
- semantic.color 의 brand.* 만 교체. 필요하면 radius 도.
- 만든 뒤 scripts/check_contrast.py 기준으로 대비비를 검증하고,
  4.5:1을 못 넘는 조합은 대안 색을 함께 제시해.
```

## D. 클로드 아티팩트로 발행할 때

```
결과물을 클로드 아티팩트로 발행할 거야. 아티팩트는 외부 리소스를 못 불러오니까
CSS 링크를 걸지 말고 이렇게 해줘.

1. git clone --depth 1 --branch v1.12.3 https://github.com/frombranch/eluon.git
2. docs/tokens/eluon-eluo.css 내용을 <style>에 인라인
3. 이미지가 필요하면 PNG를 base64 data: URI로 인라인
4. 그 상태로 단일 HTML 작성 후 발행
```

---

## 왜 "승인 전에 그리지 마"를 넣는가

자산 ID 목록을 먼저 받으면, 잘못된 방향을 **HTML 300줄이 나오기 전에** 잡을 수 있습니다.
이 한 줄이 재작업의 대부분을 없앱니다.
