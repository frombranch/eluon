이 도구는 자산 목록을 코드에 두지 않습니다. 팀의 Figma에서 자산 파일을 한 번 만들어 연결하면, 그때부터 그 자산으로만 프롬프트를 만듭니다.

01

Figma 컴포넌트에 설명을 적습니다

컴포넌트를 고르고 우측 패널의 Description 칸에 두 줄만 적으면 됩니다. 크기·라운드·여백은 Figma에서 자동으로 읽으니 적지 않아도 됩니다.

usage: 화면당 주요 액션 1개. 히어로·폼 제출·전환 유도 dont: 삭제·탈퇴 등 파괴적 액션에는 쓰지 않음

전부 적혀 있지 않아도 괜찮습니다. 빠진 컴포넌트는 다음 단계에서 알려줍니다.

02

Claude에게 자산 파일을 만들어 달라고 합니다

Figma 파일 주소를 넣으면 아래 문장에 그대로 들어갑니다. 복사해서 Claude에 붙여넣으면 컴포넌트를 읽어 자산 파일을 만들어 줍니다.

사이트 URL을 넣으세요

고객사 웹사이트 주소를 넣으면 반복되는 UI 조각을 재서 지금 라이브러리와 대조합니다. 덮이는 것과 안 덮이는 것을 표 두 개로 냅니다.

덮이는 표가 본론입니다 — 그 목록이 곧 재배치해 쓸 재료입니다. 안 덮이는 쪽은 예외이고, 새로 만드는 것은 마지막 수단입니다.

대표 페이지 하나를 넣으십시오. 다른 화면은 주소를 바꿔 다시 돌리면 됩니다.

04

05

푸시되면 반영

그때 GitHub 에 올라갑니다. 이 빌더 목록에는 다음 로드부터 나타납니다.

찾기와 만들기를 나눈 이유는 승인 없이 라이브러리가 늘어나면 안 되기 때문입니다. 라이브러리는 하나이고 테마만 갈아 끼우므로, A 고객사 때문에 넣은 자산이 B 고객사 시안에도 그대로 보입니다.
