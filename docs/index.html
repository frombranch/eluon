Typography — 어느 자리에 무엇을 쓰나

수치만 있고 역할이 없으면 제목과 본문이 다 비슷한 크기로 나옵니다. display1은 한 화면에 하나뿐이고, 위계를 건너뛰지 않습니다. 크기는 직접 쓰지 말고 var(--type-heading1-size), 또는 한 줄 축약형 font:var(--type-heading1)을 씁니다.

Korean — 한글 조판

한글은 어절 중간에서 끊기면 읽기가 확 나빠지고, 그렇다고 keep-all만 걸면 긴 영문 주소가 레이아웃을 밀어냅니다. 두 속성을 짝으로 겁니다. 줄바꿈을 <br>로 넣지 않습니다 — 폭이 바뀌면 엉뚱한 자리에서 끊깁니다.

토큰무엇값왜
text.break어절 단위 줄바꿈keep-all한글 낱자 중간에서 자르지 않습니다.
text.overflowWrap긴 문자열만 끊기anywherekeep-all 만 두면 긴 영문·URL 이 넘칩니다. 둘은 짝입니다.
text.wrap줄 끝 고르게pretty마지막 줄에 한 어절만 남는 것을 줄입니다.
text.numeric숫자 자릿수 맞춤tabular-nums한글 사이에 낀 숫자가 흔들리지 않습니다.
/* 본문에 거는 한 벌 */
word-break: var(--text-break);
overflow-wrap: var(--text-overflowWrap);
text-wrap: var(--text-wrap);

How to use

Agents

클로드에게 이 시스템을 쓰게 하는 가장 짧은 형태입니다.

자세한 템플릿은 저장소의 prompts/ 에 있습니다. 자산 ID를 추측하게 두지 말고, 항상 manifest를 먼저 읽히세요.

https://github.com/frombranch/eluon 의 CLAUDE.md 와 manifest.json 을 읽고,
거기 있는 자산으로만 <화면 이름> 시안을 만들어줘.
테마는 eluo 를 쓰고, 쓸 자산 ID 목록을 먼저 보여준 뒤
내 승인을 받고 조립해. spec 값은 바꾸지 마.
Eluon Design System · v1.12.0 · 디자인포지션 이 페이지는 scripts/build_docs.py가 manifest와 레시피에서 생성합니다.
